# 🍏 Merode Markt - Modern E-Commerce Supermarket Website

Een moderne, snelle en volledig responsieve supermarktwebsite gebouwd met **React.js** en **Vite** voor **Merode Markt**. De website is speciaal ontworpen voor mobiele apparaten en desktops (UI/UX) met een direct bestelsysteem via WhatsApp.

---

## 🚀 Live Demo
Bekijk de website live op internet: 
🔗 **[merodemarkt.vercel.app](https://vercel.app)**

---

## ✨ Kenmerken (Features)
- 📱 **Modern & Responsive Design:** Geoptimaliseerd voor smartphones, tablets en desktops.
- 🛒 **Interactieve Winkelwagen:** Producten toevoegen, aantallen wijzigen en live totaalprijzen berekenen zonder de pagina te verversen.
- 💬 **WhatsApp Bestelsysteem:** Klanten kunnen hun bestelling met één klik direct naar de winkel verzenden via een geformatteerd WhatsApp-bericht.
- 🔍 **Slimme Zoekbalk:** Direct zoeken naar specifieke supermarktproducten (bijv. groenten, zuivel, bakery).
- 🏷️ **Categorieën Filter:** Eenvoudig bladeren door verschillende afdelingen met moderne emoji-iconen en automatische tekst-wrap.
- 🔒 **Privacybeleid:** Ingebouwde pagina (Privacybeleid) die voldoet aan de eisen van Google AdSense.
- 📍 **Interactieve Kaart:** Google Maps-integratie op de contactpagina om de winkel gemakkelijk te vinden.

---

## 🛠️ Technologieën (Tech Stack)
- **Frontend Framework:** React.js (v18)
- **Build Tool:** Vite (Super snel laden)
- **Styling:** Vanilla CSS3 (Flexbox & Grid, Geen zware bibliotheken voor maximale snelheid)
- **Hosting & Cloud:** Vercel (Automatische CI/CD via GitHub)

## 💻 Lokale Installatie (Local Development)

Als u het project lokaal op uw computer wilt uitvoeren, volg dan deze stappen via de terminal:

1. **Kloon het project of download de map:**
   ```bash
   git clone https://github.com
   cd merodemarkt
   ```

2. **Installeer alle benodigde pakketten (Dependencies):**
   ```bash
   npm install
   ```

3. **Start de lokale server:**
   ```bash
   npm run dev
   ```
   *Open vervolgens [http://localhost:5173](http://localhost:5173) in uw browser.*

---

## 🔄 Hoe updates online te zetten? (Deployment)

Dit project is gekoppeld aan **Vercel** en **GitHub**. Elke wijziging die u online maakt in de repository via GitHub (zoals prijzen of productnamen aanpassen in `src/pages/Home.jsx`), zal de website automatisch binnen 15 seconden live bijwerken!

Als u lokaal via VS Code werkt, kunt u de website updaten met het volgende commando:
```bash
vercel --prod
```
